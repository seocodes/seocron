# Routes

The Vite SPA exposes one static route.

| URL | Entry                          | Layout | Content                                                                  |
| --- | ------------------------------ | ------ | ------------------------------------------------------------------------ |
| `/` | `src/main.tsx` → `src/App.tsx` | `App`  | Toggleable Timer and Stopwatch panels plus in-memory appearance controls |

There is no routing library or router configuration.
