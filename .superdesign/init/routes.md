# Routes

The Vite SPA exposes one static route.

| URL | Entry                          | Layout | Content                                                                               |
| --- | ------------------------------ | ------ | ------------------------------------------------------------------------------------- |
| `/` | `src/main.tsx` → `src/App.tsx` | `App`  | Timer and Cronômetro with in-memory appearance, scale, focus, and fullscreen controls |

There is no routing library or router configuration.
