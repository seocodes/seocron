# Shared layouts

## `src/App.tsx`

Single-page application shell: nameplate and mode switch at the top, active time instrument and shared display toolbar in the center, appearance controls at the bottom. Focus mode expands the active instrument and omits nonessential bays while preserving state. The full source file is passed directly to design drafts; this inventory records its responsibility without duplicating feature logic.

The app has no router, sidebar, navigation bar, footer, or nested layout.
